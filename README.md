# AI Cloud Ops Assistant

AI-powered cloud operations tool built using Python, AWS, Boto3, and Ollama.

## Features

### AWS Inventory Scanner
- Lists S3 buckets
- Lists IAM users
- Lists EC2 instances

### AWS Cost Optimizer
- Detects stopped EC2 instances
- Detects unattached EBS volumes

### AI Cloud Auditor
- Generates security recommendations
- Provides cost optimization suggestions
- Reviews AWS best practices
- Performs risk assessment

## Technologies Used

- AWS CLI
- Boto3
- Python
- Ollama
- Qwen AI Model
- Linux
- Git
